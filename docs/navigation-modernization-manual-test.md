# چک لیست تست دستی Navigation Modernization

این چک لیست برای تست دستی با کاربر لاگین شده است. تست‌های سرور و build انجام شده‌اند، اما بخش‌های دیداری و دسترسی‌ها باید داخل مرورگر هم دیده شوند.

## قبل از شروع

- وارد سیستم شوید.
- آدرس اصلی LAN را باز کنید: `http://192.168.170.8:3100`
- یک بار صفحه را hard refresh کنید تا build جدید لود شود.

## 1. سایدبار دسکتاپ

- سایدبار سمت راست را در حالت باز بررسی کنید.
- دکمه «جستجوی سریع فروش» باید بالای جستجوی منو دیده شود.
- دکمه باید مهم‌تر از آیتم‌های معمولی منو دیده شود، ولی از ظاهر کلی سیستم بیرون نزده باشد.
- منو باید اسکرول شود، اما این دکمه بالای سایدبار بماند.
- روی دکمه بزنید؛ باید فوری وارد `/sales/search` شوید.
- هنگام کلیک باید افکت کوچک آیکن‌های شناور دیده شود.

## 2. حالت جمع شده سایدبار

- سایدبار را collapse کنید.
- دکمه «جستجوی سریع فروش» باید به صورت آیکن تنها دیده شود.
- tooltip باید نام دکمه را نشان دهد.
- کلیک روی آیکن باید همچنان کاربر را به `/sales/search` ببرد.

## 3. ترتیب ماژول‌ها

- ترتیب ماژول‌های اصلی در ستون آیکن‌ها را بررسی کنید.
- هیچ ماژول اصلی نباید گم شده باشد.
- مسیرهای مهم قبلی باید همچنان از منو قابل دسترسی باشند.

## 4. جستجوی داخل منو

- داخل جستجوی سایدبار چند عبارت فارسی و لاتین تست کنید.
- نمونه‌ها: `فروش`، `مشتری`، `اعتبار`، `receipt`، `capital`
- نتیجه‌ها باید از Registry بیایند و فقط مسیرهایی را نشان دهند که کاربر اجازه دیدنشان را دارد.

## 5. اکشن اصلی نقش

- بالای منو، اکشن اصلی نقش کاربر را بررسی کنید.
- برای نقش‌های مختلف، اکشن باید با دسترسی همان نقش هماهنگ باشد.
- اگر کاربر اجازه یک route را ندارد، نباید آن route به عنوان اکشن اصلی نشان داده شود.

## 6. نیازمند اقدام

- بخش «نیازمند اقدام» را بررسی کنید.
- بیشتر از ۳ مورد نباید نمایش داده شود.
- badge فقط برای چیزی نمایش داده شود که واقعاً نیاز به اقدام دارد.
- اگر count صفر است، آن آیتم نباید شلوغی اضافه کند.

## 7. میانبرهای من

- روی pin یا ستاره کنار چند آیتم مجاز بزنید.
- حداکثر ۵ میانبر باید ذخیره شود.
- صفحه را refresh کنید؛ میانبرها باید باقی بمانند.
- unpin را تست کنید؛ آیتم باید حذف شود.
- مسیرهایی که کاربر اجازه ندارد نباید در میانبرها دیده شوند.

## 8. آخرین استفاده‌ها

- وارد چند صفحه اصلی شوید.
- به سایدبار برگردید و بخش آخرین استفاده‌ها را بررسی کنید.
- مسیرهای تکراری نباید چند بار پشت سر هم بیایند.
- مسیرهای جزئی با ID خام نباید به شکل زشت یا حساس ذخیره شوند.

## 9. Breadcrumb

- چند صفحه اصلی و چند صفحه داخلی را باز کنید.
- breadcrumb باید کوتاه و قابل فهم باشد.
- ID خام مشتری، محصول یا فاکتور نباید در breadcrumb نمایش داده شود.
- PageHeader قدیمی صفحه‌ها نباید خراب یا تکراری شده باشد.

## 10. Command Palette

- کلید `Ctrl+K` را بزنید.
- پنجره جستجوی کلی باید باز شود.
- وقتی داخل input یا textarea تایپ می‌کنید، `Ctrl+K` نباید مزاحم تایپ شود.
- عبارت‌هایی مثل `فروش`، `مشتری`، `capital` و `receipt` را جستجو کنید.
- روی یک نتیجه بزنید؛ باید به همان route برود.
- با `Esc` باید بسته شود.

## 11. مسیر تست اصلی

- مسیر `/gamification/admin/manual-metrics` را باز کنید.
- صفحه باید بدون خطای سفید، crash یا missing route باز شود.
- اگر کاربر اجازه ندارد، رفتار باید با permission موجود هماهنگ باشد و route guard نباید دور زده شود.

## 12. موبایل و اندازه کوچک

- عرض مرورگر را کم کنید یا با موبایل باز کنید.
- bottom navigation نباید خراب شود.
- سایدبار offcanvas باید همچنان قابل استفاده باشد.
- دکمه‌ها و متن‌ها نباید روی هم بیفتند.

## 13. Dark Mode

- اگر dark mode فعال است، همان مسیرها را در dark mode ببینید.
- رنگ badge، دکمه اصلی، جستجو، hover و active state باید خوانا باشد.

## نتیجه تست

- اگر همه موارد بالا درست بود، Navigation Modernization از نظر دستی قابل قبول است.
- اگر چیزی دیده نشد، اول مطمئن شوید مرورگر build جدید را گرفته و صفحه hard refresh شده است.
- اگر مشکل مربوط به permission بود، همان کاربر و role دقیق را در گزارش بنویسید.
