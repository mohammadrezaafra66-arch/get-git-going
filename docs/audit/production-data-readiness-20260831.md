## Q1 — شکاف کد آسان

### تابعی که همه‌چیز به آن گیر می‌کند

```sql
SELECT pg_get_functiondef(oid) FROM pg_proc
 WHERE pronamespace='public'::regnamespace AND proname='require_asan_code';
```

```sql
CREATE OR REPLACE FUNCTION public.require_asan_code(p_person_id uuid)
 RETURNS text LANGUAGE plpgsql STABLE SET search_path TO 'public'
AS $function$
...
  SELECT NULLIF(btrim(pi.value_normalized), '')
    INTO _code
    FROM public.person_identifiers pi
   WHERE pi.person_id = p_person_id
     AND pi.kind = 'asan_person_code'
   LIMIT 1;

  IF _code IS NOT NULL THEN RETURN _code; END IF;
  ...
  RAISE EXCEPTION 'کد آسان برای «%» ثبت نشده است؛ ابتدا کد آسان او را وارد کنید،
                   سپس سند را ثبت کنید', _name USING ERRCODE = 'P0001';
END;
$function$
```

پس کد آسان یک ردیف در `public.person_identifiers` است با `kind = 'asan_person_code'`،
و مقدارِ خوانده‌شده ستون `value_normalized` است.

این بازماندهٔ probe مهاجرت ۴۰۲ است. ۴۰۲ تنها migration ای بود که بدون

به‌جای rollback شدن **commit شد**. زمانش — ۰۶:۱۴:۳۴ روز ۲۰۲۶-۰۹-۰۱ — دقیقاً وسط اجرای
مهاجرت است.

خودِ فیش دست‌نخورده است. اثرش این است که آن فیش در رابط کاربری یک پیوست جعلی
به نام `402-probe/two` نشان می‌دهد. **من پاکش نکردم** چون این مأموریت فقط‌خواندنی است.

## تأیید نشده

1. **هیچ صفحه‌ای در مرورگر باز نشد.** مسیرها و دسترسی‌ها از رجیستری ناوبری و فایل‌های
   route خوانده شد، نه از رابط واقعی. **چه چیزی قطعی‌ترش می‌کند:** باز کردن
   `/persons/{id}` و `/accounting/bank-accounts` با حساب حسابدار.
2. **فرم کد آسان با داده واقعی آزموده نشد** — چون نوشتن ممنوع بود.
3. **قالب و اعتبارسنجی کد آسان.** `normalizeIdentifier(kind, value)` در
   `identifiers-normalize.ts` هست ولی قاعده‌اش را باز نکردم. طول و قالب مجاز کد آسان
   نامعلوم است.
4. **۱۱۶ پیش‌فاکتور بدون `customer_person_id`** — نگاه نکردم چرا لینک ندارند و آیا
   قابل وصل شدن‌اند.
5. **تخمین زمان‌ها در چک‌لیست پایین حدسی‌اند** و بر پایهٔ تعداد فیلد فرم زده شده‌اند،
   نه اندازه‌گیری واقعی.

## حل‌نشده

1. **۱۱۶ پیش‌فاکتور پذیرفته‌شده لینک شخص ندارند.** برای آن‌ها کد آسان قابل ثبت نیست.
   اگر برای این‌ها هم سند لازم است، اول باید به شخص وصل شوند.
2. **ردیف زائد `402-probe/two`** روی فیش واقعی تولید مانده است.
3. **کد آسان گروهی وارد نمی‌شود** — ۲۲ ورودی دستی.

## برای ثبت اولین سند چه چیزی لازم است

چک‌لیست به ترتیب اجرا. زمان‌ها تخمینی‌اند.

### گام ۱ — یک حساب بانکی بسازید ‹۵ دقیقه›

**کجا:** `/accounting/bank-accounts` → دکمهٔ افزودن

**چه چیزی وارد کنید:**
- **عنوان** (اجباری) — مثلاً «حساب جاری ملت»
- **نام بانک** (اجباری) — مثلاً «ملت»
- **کد حسابداری** (فرم می‌گوید اختیاری، **ولی حتماً پرش کنید** وگرنه سند ثبت نمی‌شود)
- **نوع حساب** — `bank` برای حساب بانکی، `cash` برای صندوق. فقط همین دو
- **فعال** را روشن بگذارید
- شماره شبا / شماره حساب / شماره کارت اختیاری‌اند و ماژول نمی‌خواندشان
