# Torob Module Spec

## Phase label

PHASE-1 candidate after Phase 0 acceptance.

## Purpose

Define the future limited Torob market/pricing intelligence module.

## Phase 0 status

No implementation in Phase 0.

Only documentation, contracts and dummy worker foundation are allowed.

## Future scope

A future limited module may cover:

- product input contract
- public price observation contract
- seller/offer normalization contract
- product matching contract
- pricing output contract
- run status reporting through automation jobs

## Out of scope for Phase 0

- real Torob scraping
- production price extraction
- browser automation
- proxy/account management
- external platform calls
- pricing decisions affecting production
