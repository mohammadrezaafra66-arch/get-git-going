# Divar Future Module Spec

## Phase label

FUTURE

## Purpose

Define the future Divar lead acquisition module as a documented future capability only.

## Phase 0 status

No implementation in Phase 0.

Divar is explicitly not part of Phase 0.

## Future scope

A future module may require:

- approved legal/public-data scope
- driver contract
- rate-limit policy
- account safety policy
- lead extraction contract
- deduplication contract
- run status reporting through automation jobs

## Out of scope for Phase 0

- real Divar crawling
- real message sending
- account automation
- browser automation
- proxy management
- production lead extraction
- private or non-public data collection

## Hard rule

This module must remain `FUTURE` until a later ADR explicitly moves it into an implementation phase.
