# Project Scope

## Scope labels

- `BASELINE`: current repository state.
- `PHASE-0`: infrastructure/documentation/contracts preparation only.
- `PHASE-1`: limited MVP.
- `FUTURE`: not to be built now.

## Phase guard

Do not build real Divar, WhatsApp, Instagram, Torob, OCR/STT, AI, browser automation, proxy management, production scraping, or production sending in Phase 0.
