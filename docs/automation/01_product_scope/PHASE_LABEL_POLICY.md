# Phase Label Policy

## Labels

- `BASELINE`: current repository state.
- `PHASE-0`: infrastructure, documentation, contracts and safe placeholders only.
- `PHASE-1`: limited MVP after Phase 0 acceptance.
- `FUTURE`: explicitly not built now.

## Hard rule

If a task is related to Divar, WhatsApp, Instagram, Torob, OCR/STT, AI, real browser automation, real proxy/account management, production scraping, or production sending, it must be labeled `FUTURE` unless a later ADR moves it into `PHASE-1` or beyond.
