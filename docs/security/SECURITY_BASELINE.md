# Security Baseline فاز صفر

Phase Label: PHASE-0  
Owner: محمدرضا افرا  
Status: Active

## 1. اصل اصلی

امنیت فاز صفر یعنی جلوگیری از اشتباه‌های پایه‌ای قبل از ساخت ربات‌های واقعی. در این فاز هیچ secret، service role، token یا credential نباید وارد فرانت‌اند، لاگ، سند عمومی یا Drive شود.

## 2. قوانین اجباری

1. Service Role Supabase فقط سمت server/worker مجاز است.
2. هیچ secret در React/TanStack/Lovable مجاز نیست.
3. RLS باید برای جدول‌هایی که از client قابل دسترسی‌اند بررسی شود.
4. داده‌های حساس در لاگ خام ثبت نشوند.
5. هر migration باید اثر امنیتی خود را اعلام کند.
6. Worker Dummy فقط با token/test config امن اجرا شود.
7. هیچ اتصال واقعی به پلتفرم خارجی در فاز صفر مجاز نیست.

## 3. داده‌های حساس

نمونه داده‌های حساس:

- شماره موبایل مشتریان
- پیام‌ها و چت‌ها
- tokenها
- cookieها
- service keyها
- credential اکانت‌ها
- اطلاعات مالی و پرداخت

## 4. ممنوعیت‌ها

- ذخیره `.env` واقعی در GitHub.
- قراردادن کلیدها در Google Drive.
- ارسال secret به Cursor یا Lovable در متن prompt.
- ساخت API بدون auth/access rule.
- دور زدن RLS برای سرعت توسعه.

## 5. معیار پذیرش امنیتی PR

هر PR فاز صفر باید گزارش دهد:

1. آیا migration دارد؟
2. آیا RLS/RBAC impact دارد؟
3. آیا secret جدید نیاز دارد؟
4. آیا داده حساس درگیر است؟
5. آیا لاگ‌ها امن هستند؟

## 6. قانون توقف

اگر مالک امنیت یا محمدرضا افرا نتواند اثر امنیتی تغییر را تأیید کند، PR نباید merge شود.
