# ماژول ۰۸ — مشتریان و اعتبار

**تستر مسئول:** آرمین (`test.sales`) برای مشتریان؛ حانیه (`test.accountant`) برای اعتبار/قوانین اعتبار. تست منفی: محمدرضا (`test.viewer`).
**مسیرها:** `/sales/customers`، `/sales/customers/create`، `/sales/customers/$id/edit`، `/sales/customers/$id/credit`، `/sales/credit-customers`، `/sales/credit-rules`، `/sales/customers/import`.

## الف) این ماژول چه کاری می‌کند
مشتریان ثبت و مدیریت می‌شوند؛ هر فروشنده فقط مشتریان خودش (و مشتریان بدون‌مسئول) را می‌بیند. حسابدار سقف و وضعیت اعتبار مشتری را می‌بیند و قوانین اعتبار را تنظیم می‌کند. امکان ورود گروهی مشتریان (import) هم هست.

> پیش‌نیاز: seed اجرا شده (مشتریان `QA-`). آرمین رکوردهایش را `ARM-` بسازد.
