# ماژول ۱۵ — جداول دادهٔ پویا

**تستر مسئول:** حانیه (`test.accountant`). تست منفی: آرمین (`test.sales`)، محمدرضا (`test.viewer`).
**مسیرها:** `/data-tables`, `/data-tables/new`, `/data-tables/$tableId`.

## الف) این ماژول چه کاری می‌کند
کاربر می‌تواند «جدول داده» دلخواه بسازد (ستون‌ها با نوع‌های مختلف: متن، عدد، تاریخ، وضعیت، تگ) و ردیف وارد کند — مثل یک صفحه‌گستردهٔ سبک. **دسترسی به هر جدول ترکیبی از نقش و سطح دسترسی جدول است** (RLS: `access_level` + `allowed_roles`)، پس این ماژول برای تست «نقش + برچسب» کلیدی است.

> پیش‌نیاز: با `test.accountant` وارد شو. جدول‌ها را با پیشوند `HAN-` بساز.

| DT-N01 | جدول `finance_only` + `test.sales` | P0 | جدولی با سطح `finance_only` بساز (حانیه)؛ سپس با `test.sales` فهرست جداول را ببین | جدول `finance_only` **نباید** برای sales دیده شود (RLS `dyn_table_role_can_view`: finance_only→accountant) | | |
