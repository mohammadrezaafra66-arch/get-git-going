# ماژول ۱۶ — کلیدهای API ربات و یکپارچه‌سازی

**تستر مسئول:** حانیه (`test.manager`)؛ بخش‌های admin با `test.admin` (محمدرضا). تست منفی: آرمین (`test.sales`)، محمدرضا (`test.viewer`).
**مسیرها:** `/bot-api-keys`, `/bot-api-keys/docs`, `/bot-api-keys/playground`, `/bot-api-keys/usage`, `/integrations/didar`, `/market-matches`.

## الف) این ماژول چه کاری می‌کند
برای ربات‌های بیرونی (مثل ربات تلگرام/واتساپ) «کلید API» ساخته می‌شود که دسترسی‌اش به محصولات از طریق **برچسب محصول** و به جداول داده محدود می‌شود. «بررسی تطبیق محصولات بازار» تطبیق محصولات با منابع بیرونی (ترب/…) را تأیید/رد می‌کند.

> ⚠️ نکتهٔ RLS: فیلتر برچسبِ محصول فقط برای همین کلیدهای ربات اعمال می‌شود (نه برای کاربران لاگین‌شده) — از توابع SECURITY DEFINER `bot_get_product_for_key`.
