# انتشار و بازگشت — انتخابگر مشتری در فرم پیش‌فاکتور

گام ۱ و ۲ فاز ۲. شاخه `feature/quote-customer-picker-readonly`.

## پرچم‌ها

| پرچم | وضعیت | معنا |
|---|---|---|
| `VITE_FEATURE_QUOTE_CUSTOMER_PICKER` | **روشن روی استیجینگ** | اتصال = شناسه؛ نام/شماره فقط‌خواندنی؛ قطع اتصال صریح؛ افزودن شماره به پرونده |
| `VITE_FEATURE_QUOTE_IDENTITY_FROM_RECORD` | **خاموش، عمداً** | خواندن نام/شماره از رکورد. تا صفر شدن «مشتریان فعال بدون شماره» روشن نمی‌شود |

پرچم فقط وقتی روشن است که مقدارش **دقیقاً** رشتهٔ `true` باشد. هر مقدار دیگر — و نبودِ متغیر —
خاموش است. یعنی غلط تایپی به‌جای روشن‌کردنِ ناخواسته، خاموش می‌ماند.

## ⚠️ بازگشت نیازمند rebuild است

Vite متغیرهای `VITE_` را **زمان build** داخل bundle می‌پزد. پس برخلاف یک پرچم زمان‌اجرا،
**تغییر متغیر به‌تنهایی هیچ اثری ندارد** — bundle قدیمی همان مقدار قبلی را در خود دارد.
هر بازگشتی یک rebuild است.

## روش بازگشت

**چه کسی:** هر کسی که به سرور تست دسترسی دارد (`D:\AfraKalaTest\app`).
**چقدر طول می‌کشد:** حدود ۳ تا ۵ دقیقه — عمدتاً زمان build.

```powershell
# ۱. پرچم را خاموش کن
#    در deploy/lan/.env.lan خط زیر را حذف یا مقدارش را عوض کن:
#    VITE_FEATURE_QUOTE_CUSTOMER_PICKER=true

# ۲. دوباره build و بالا بیاور — --no-deps الزامی است
$env:GIT_SHA = (git rev-parse --short HEAD)
$env:BUILD_TIME = (Get-Date -Format o)
docker compose --env-file deploy/lan/.env.lan -f deploy/lan/docker-compose.yml `
  up -d --no-deps --build web

# ۳. تأیید کن که برگشت
docker inspect afrakala-lan-web --format "{{range .Config.Env}}{{println .}}{{end}}" |
  Select-String "APP_GIT_SHA"
```

**تأیید اینکه واقعاً برگشت:** در فرم پیش‌فاکتور، کادرهای «نام مشتری» و «شماره تماس» دوباره قابل
تایپ می‌شوند و دکمهٔ «قطع اتصال / ثبت به‌عنوان مهمان» ناپدید می‌شود.

## آنچه بازگشت لمس **نمی‌کند**

- **هیچ مایگریشنی** — این انتشار هیچ تغییر schema نداشت
- **هیچ داده‌ای** — هیچ ردیفی نوشته، به‌روز یا حذف نشد
- **هیچ RLS یا سطح دسترسی**
- **شماره‌هایی که تیم از راه دکمهٔ جدید به پروندهٔ مشتری اضافه کرده** — این‌ها دادهٔ درست‌اند و
  می‌مانند. بازگشتِ پرچم فقط راه *افزودن* را برمی‌دارد، نه آنچه افزوده شده.

## بازگشت جزئی

اگر فقط گیت نقشِ دکمهٔ قطع اتصال مشکل داشت (نه کل انتخابگر)، به کامیت قبلی برگردید نه به
پرچم — بازگشت پرچم هر دو گام را باهم برمی‌دارد و ۵۹٪ مشتریانِ بدون شماره را دوباره غیرقابل فروش
می‌کند.
